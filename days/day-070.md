## ② 核心知识精讲
### 2.1 博弈论：四个要素、两类博弈、一个均衡

**博弈**是多个决策主体在相互影响的情况下各自选择策略、并共同决定结果的过程。分析一个博弈，先把四样东西说清：

- **参与人**：谁在做决策；
- **策略**：每个人可以选哪些行动；
- **支付（收益）**：每种策略组合下各人得到什么；
- **信息**：各自知道些什么。

在此之上还有**均衡**——大家都不愿单方面改变策略的稳定状态，最常考的是**纳什均衡**：在给定其他人策略不变的前提下，任何一方单独改变自己的策略都不会得到更好的结果。注意它描述的是"谁都不想单独动"，**不必然是社会最优**。经典的囚徒困境说的就是这件事：两个人各自选对自己最有利的策略，结果双双落到次优结局——**个体理性不等于集体理性**。

按不同维度，博弈可以分成几类：

| 分类维度 | 类型 | 要点 |
|---|---|---|
| 按总收益 | 零和 / 非零和 | 零和是一方所得即另一方所失，总支付为零；非零和可能出现双赢或双输 |
| 按合作与否 | 合作 / 非合作 | 能否形成有约束力的协议 |
| 按决策次序 | 静态 / 动态 | 同时决策，还是先后行动并可观察对方 |

项目管理里，招标谈判、供应商价格博弈、多部门争资源，本质都是博弈。理解纳什均衡的价值在于：**你能预判对方在给定规则下会怎么选**，从而设计规则（如合同条款、激励机制），把均衡引向对项目有利的方向。案例题里"两家供应商恶性压价、最后都亏"就是非合作博弈落入囚徒困境的写照，改进方向是建立长期合作机制、明确质量与交付约束，把非合作博弈转为合作博弈。

### 2.2 排队论：M/M/1 五个指标，一条稳定线

排队论研究"到达—排队—服务"的系统。考试基本只考 **M/M/1**：到达服从泊松分布、服务时间服从负指数分布、**单服务台**、先到先服务。符号含义是固定的：

- **λ**（到达率）：单位时间平均到达多少个；
- **μ**（服务率）：单位时间一个服务台平均能服务多少个；
- **ρ = λ / μ**：服务台利用率，也叫服务强度。

**稳定条件是 ρ < 1，即 λ < μ**。这不是数学洁癖：如果到达比服务快，队伍会无限增长，系统永远排不完。题目里若算出 λ ≥ μ，答案不是"队长无穷大"，而是"系统不稳定，需增加服务台或提高服务率"。

M/M/1 的常用指标是一组，建议整组背下来：

> ρ = λ / μ　　P₀ = 1 − ρ（系统空闲概率）
> 平均队长 L = ρ / (1 − ρ)
> 平均等待队长 Lq = ρ² / (1 − ρ)
> 平均逗留时间 W = 1 / (μ − λ)
> 平均等待时间 Wq = λ / [μ(μ − λ)]

还有一个小李特尔公式（Little 公式）把它们串起来：**L = λW，Lq = λWq**。记不住 Wq 的公式时，可以用 Lq = λWq 反推。

> **微型算例**：λ = 4 人/小时，μ = 5 人/小时。ρ = 0.8，L = 0.8/0.2 = **4 人**，Lq = 0.64/0.2 = **3.2 人**，W = 1/(5−4) = **1 小时**，Wq = 4/(5×1) = **0.8 小时**。

请特别感受一下这个算例的"非线性"：利用率从 0.8 提到 0.9，λ 只涨了 12.5%，但 L 从 4 人涨到 9 人、W 从 1 小时涨到 2 小时。**利用率逼近 1 时，等待时间会急剧上升**。这条规律在 IT 运维、服务台、审批流程里全都成立，也是案例题里"系统上线后响应越来越慢"的经典解释——不是服务器不够快，是长期贴着满负荷跑。

### 2.3 存储论：EOQ 就是在"订货费"和"保管费"之间找平衡

库存管理的核心矛盾很朴素：一次订得多，订货次数少、订货成本低，但货压在仓库里，持有成本高；一次订得少，持有成本低，但频繁下单，订货成本高。**经济订货批量（EOQ）**就是让两者之和最小的那个订货量。

标准 EOQ 模型的假设要先说清：需求均匀且已知、瞬时到货、不允许缺货、订货成本与单位持有成本固定、单价不变。在这个前提下：

> Q* = √(2DS / H)
> 年订货次数 N = D / Q*
> 年总相关成本 TC = √(2DSH)

其中 D 是年需求量，S 是每次订货成本，H 是单件年持有成本。EOQ 有一个漂亮的性质：**在最优批量处，年订货成本恰好等于年持有成本**，总成本最小。这个性质可以用来验算——如果你算出的两个成本差得很多，八成是开方或单位错了。

> **微型算例**：D = 1000 件/年，S = 100 元/次，H = 5 元/件·年。Q* = √(2 × 1000 × 100 / 5) = √40000 = **200 件**；N = 1000/200 = **5 次/年**；TC = √(2 × 1000 × 100 × 5) = **1000 元/年**。

考场上三个坑：一是**单位不统一**（年需求配月持有成本）；二是把 S（每次订货成本）和 H（单件年持有成本）代反；三是问"订货次数"却答了"订货批量"。看清问的是 Q、N 还是 TC，一眼就能避掉。

### 2.4 第21章计算题汇总：一张表收口

到这儿，科学基础的计算题已经全了。考前只看这张表，能覆盖绝大多数出题方式：

| 题类 | 核心公式或方法 | 最常见的坑 |
|---|---|---|
| 线性规划 | 变量—目标—约束，图解法取顶点 | 漏非负约束、忘比较所有顶点 |
| 最短路径 | Dijkstra，边权须非负 | 与最小生成树混淆 |
| 最小生成树 | Prim 从点长、Kruskal 排边避圈 | 选边成圈、漏连节点 |
| 关键路径 | 正推 ES/EF、逆推 LS/LF，总时差为 0 即关键 | 总时差与自由时差混用 |
| 资源优化 | 平衡动工期、平滑不动工期 | 把两者说反 |
| 风险型决策 | 期望值 = Σ(概率×损益) − 投资 | 忘减投资、概率和不为 1 |
| 不确定型决策 | 乐观/悲观/折中/等可能/后悔值 | 后悔值准则方向做反 |
| 排队论 | ρ = λ/μ，L = ρ/(1−ρ)，W = 1/(μ−λ) | 忘稳定条件 λ < μ |
| 存储论 | Q* = √(2DS/H) | 单位不统一、S 与 H 代反 |

复习方法建议"三遍法"：**第一遍认题型**（看题眼判断套哪个模型）；**第二遍练纯计算**（只给数据、只求数值，练速度和准确率）；**第三遍练带单位的应用题**（把业务话翻译成公式）。三遍都过，这类题在考场上就是稳拿分。

> **记忆抓手**：博弈四要素"人、策略、支付、信息"，纳什均衡是"谁都不想单独变"；排队先看 ρ = λ/μ，稳定必须小于 1；存储论 EOQ 一开方，最优处订货成本等于持有成本。

## ③ 高频易错点
1. **易错点**：把纳什均衡当成"对整体最优的结果" → **正解**：纳什均衡只表示任何一方都**不愿单方面改变**策略，可能是次优结局，囚徒困境就是典型例子。
2. **易错点**：算出 λ ≥ μ 后回答"队长无穷大" → **正解**：应指出系统**不稳定**、队伍将持续增长，需增加服务台或提高服务率，而不是套公式算出一个数。
3. **易错点**：把 ρ 当成"平均队长" → **正解**：ρ = λ/μ 是**服务台利用率**；平均队长 L = ρ/(1−ρ)，两者数值可能相近但含义完全不同。
4. **易错点**：EOQ 公式里把每次订货成本 S 与单件年持有成本 H 代反 → **正解**：S 在分子、H 在分母，Q* = √(2DS/H)；代反后结果往往差一个数量级。
5. **易错点**：认为订货批量越大总成本越低 → **正解**：订货成本随批量增大而下降，持有成本随批量增大而上升，**总相关成本在 EOQ 处最小**，过大或过小都会增加总成本。

## ⑤ 参考答案与解析
**答案速查**：1.B　2.C　3.A　4.B　5.A　6.C　7.B　8.D

**1. B**　解析：纳什均衡的核心是"给定他人策略，无人愿单方面改变"。A 混淆了均衡与整体最优，均衡可能是次优；C 零和博弈确有均衡，但均衡不限于零和；D 有约束力协议是合作博弈的特征。

**2. C**　解析：双方各自追求自身最优、无法形成有约束力的合作协议，最终双双受损，是典型的囚徒困境。A 零和不存在"合作解"式的双赢；B 未体现先后行动；D 结果并非帕累托最优。

**3. A**　解析：零和博弈中一方所得等于另一方所失，总支付为零。B 与零和定义矛盾；C 零和博弈通常存在均衡（如混合策略均衡）；D 零和博弈恰是非合作的典型。

**4. B**　解析：ρ = 4/5 = 0.8，L = ρ/(1−ρ) = 0.8/0.2 = 4 人。A 是平均等待时间（小时）的数值；C 是服务率；D 是平均等待队长 Lq。

**5. A**　解析：只有到达率小于服务率（ρ < 1），队伍才不会无限增长。B、C 都会导致队列持续累积；D 显然不成立。

**6. C**　解析：Q* = √(2DS/H) = √(2×1000×100/5) = √40000 = 200 件。A 把单件年持有成本当成 10 元（√10000 = 100）；B 漏乘系数 2（√20000 ≈ 141）；D 多乘了系数 4（√160000 = 400）。

**7. B**　解析：N = D/Q* = 1000/200 = 5 次/年。A 对应批量 250 件；C 对应批量 100 件；D 对应批量 50 件。

**8. D**　解析：由 Little 公式 L = λW，λ 固定时队长与逗留时间成正比。A 利用率越高等待越长；B EOQ 处总相关成本最小，批量过大过小都增加成本；C Wq 显然与到达率有关。

**案例参考答案要点**

**问题1（6 分）**

λ = 4 个/小时，μ = 5 个/小时。

- 利用率 ρ = λ/μ = 4/5 = **0.8**（即 80%）。（2 分）
- 平均队长 L = ρ/(1−ρ) = 0.8/0.2 = **4 个**。（2 分）
- 平均等待时间 Wq = λ/[μ(μ−λ)] = 4/(5×1) = **0.8 小时**（约 48 分钟）。（1 分）
- 因 ρ = 0.8 < 1，即 λ < μ，系统**稳定**，队列不会无限增长。（1 分）

（若用 W = 1/(μ−λ) = 1 小时回答"平均逗留时间"，并注明与等待时间的区别，同样给分。）

**问题2（6 分）**

D = 1000 件/年，S = 100 元/次，H = 5 元/件·年。

- 经济订货批量 Q* = √(2DS/H) = √(2×1000×100/5) = √40000 = **200 件**。（3 分）
- 年订货次数 N = D/Q* = 1000/200 = **5 次/年**。（1 分）
- 年总相关成本 TC = √(2DSH) = √(2×1000×100×5) = **1000 元/年**。（2 分）

（可加一句验算：此时年订货成本 = 5×100 = 500 元，年持有成本 = 200/2×5 = 500 元，两者相等，说明确实处于最优批量。）

**问题3（4 分）**

λ = 4.5，μ = 5，ρ = 0.9。

- 平均队长 L = 0.9/0.1 = **9 个**；平均等待时间 Wq = 4.5/(5×0.5) = **1.8 小时**（约 108 分钟）。（3 分）
- 管理含义：到达率仅上升 12.5%，但平均队长由 4 个增至 9 个、等待时间由 0.8 小时增至 1.8 小时，均**翻倍以上**。说明系统利用率逼近 1 时性能急剧恶化，应通过**增加服务台（改为多服务台）、提高服务效率、分流常见请求或设置自助服务**等措施降低 ρ，而不是等到投诉爆发再处理。（1 分）
