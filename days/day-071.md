## ② 核心知识精讲
### 2.1 组织治理：给组织装一套"方向盘 + 刹车 + 行车记录仪"
组织治理，说的是组织为了实现自身目标，对**决策、执行、监督**做出的制度安排，核心是**权责利的制衡**：谁拍板、谁干活、谁盯着、谁担责，边界要清、责任要能追溯到人。

它有四个绕不开的关键词：

- **方向**：确定组织的使命、愿景与战略目标，决定"往哪走"；
- **监督**：对经理层的经营行为进行监督，防止内部人控制；
- **问责**：决策失误、经营失当要有人负责，责任可追溯；
- **透明**：重大信息要向出资人、监管方、利益相关方披露。

常见的组织治理结构，是**决策权、执行权、监督权相互分离又相互制衡**的一套班子：

| 机构 | 定位与主要职责 | 落到项目上的体现 |
|---|---|---|
| 股东（大）会 | 最高权力机构，决定重大投资、合并分立等事项 | 批准重大投资方向、项目组合盘子 |
| 董事会 | 决策机构，定战略、选聘监督经理层 | 审批重大项目立项与重大变更 |
| 监事会 | 监督机构，监督董事与高管依法履职 | 审计、合规与专项检查 |
| 经理层 | 执行机构，负责日常经营管理 | 组织项目实施、调配资源 |

一句话记住：**股东会出钱、董事会拍板、监事会盯人、经理层干活**。

治理和管理最容易混。用一张表切开：

| 对比项 | 治理 | 管理 |
|---|---|---|
| 回答什么 | 做什么、为什么做（做正确的事） | 怎么做、谁来做（把事做正确） |
| 主体层级 | 组织最高层，董事会为核心 | 各层级经理层，项目经理在这一层 |
| 主要手段 | 制度、授权、监督、问责、披露 | 计划、组织、领导、控制 |
| 时间视角 | 长期、战略性 | 中短期、战术与执行 |

考场上命题人常在这里挖坑：把"项目经理编制项目管理计划"说成治理活动，或者反过来把"董事会审批项目立项"说成管理活动。判据只有一个——**涉及方向、授权、监督、问责的是治理；涉及资源组织与执行落地的是管理**。顺便把第3章的 IT 治理接上：IT 治理是组织治理在 IT 领域的延伸，关注 IT 的**价值、风险、资源**三大任务；第22章讲的是范围更大的组织通用治理，两者是"整体—局部"的关系，不是并列关系。

### 2.2 战略三层：公司层选题、业务层选招、职能层选配
战略不是一个笼统的词，它分三层，每层回答的问题完全不同：

| 层次 | 回答什么问题 | 典型内容 |
|---|---|---|
| 公司层（总体战略） | 我们做哪些业务、资源在业务间怎么分 | 发展型、稳定型、收缩型；一体化、多元化 |
| 业务层（竞争战略） | 在某个业务里靠什么赢 | 成本领先、差异化、集中化 |
| 职能层 | 各职能怎么支撑上面两层 | 研发、生产、营销、人力、财务战略 |

波特的三种基本竞争战略——**成本领先、差异化、集中化**——属于**业务层**，这是最高频的一个陷阱：题干里出现"某事业部在细分市场主打低价"，你选业务层；出现"集团决定退出房地产业务、聚焦新能源"，你选公司层。

战略管理的过程是四步闭环：**战略分析 → 战略制定（选择）→ 战略实施 → 战略评价与控制**。

- **战略分析**：向外看环境（宏观环境、行业竞争格局），向内看家底（资源、能力、核心专长），再用 SWOT 把内外匹配成 SO、WO、ST、WT 四类组合；
- **战略制定**：定目标、定业务组合、定竞争方式，形成战略方案并做选择；
- **战略实施**：把战略目标分解为年度经营计划、预算、组织调整与**项目组合**；
- **战略评价与控制**：用绩效指标跟踪偏差，及时纠偏或调整战略。

这里有一条必须建立的认知：**项目是战略落地的载体**。战略目标往下分解，落到项目组合，再落到项目集和项目；战略一变，项目组合的优先级就得重排。案例里那句"项目按期保质交付了，但上线后没人用、业务指标没变化"，标准答法里必须有一句——**项目目标与组织战略目标脱节，立项时未做战略对齐与商业论证**。这不是项目经理一个人的锅，是治理层面立项把关的问题。

### 2.3 组织文化：看得见的是物质，改得动的是制度，最难动的是精神
组织文化分三层，从外到内：

- **物质层**：办公环境、标识、着装、宣传栏、仪式活动——最表层，一眼能看见；
- **制度层**：规章制度、流程规范、考核与奖惩办法——把理念变成规则；
- **精神层**：使命、愿景、价值观、经营理念——最深层，决定大家真正按什么逻辑做事。

> **记忆抓手**：精神定调、制度定格、物质定相；三层里精神层是核心，物质层最表浅。判断"某公司墙上贴满标语但考核只看短期利润"，说明它的**精神层与制度层打架**，文化是虚的。

文化对项目的影响很实在：强文化能降低沟通成本、减少协调摩擦；但文化不兼容时，并购整合项目、外包合作项目、跨组织联合项目最容易集体翻车——不是技术问题，是"我们这儿一直这么干"的问题。

### 2.4 组织变革：解冻、变革、再冻结
勒温把变革分成三段，顺序不能乱：

1. **解冻**：制造紧迫感、讲清不变革的后果、松动旧习惯与旧利益格局；
2. **变革**：新流程、新结构、新技能落地，靠试点、培训、辅导推进；
3. **再冻结**：把新做法固化进制度、流程、考核与岗位职责，防止反弹回潮。

阻力的来源分两头：个人层面是习惯、安全感、利益受损、信息不对称、对未知的恐惧；组织层面是结构惯性、资源约束、权力格局重排、过去成功经验的束缚。化解阻力的手段也有对应套路：**沟通宣导、让关键人参与、培训与支持、分阶段试点、必要时由高层强制推动**。

案例里那个经典场面——"新系统上线三个月，一线又偷偷用回 Excel"——本质是**解冻不足 + 再冻结缺失**：上线前没讲清为什么改，上线后没把新流程写进考核。答这个点，比答"员工素质不高"值钱得多。

## ③ 高频易错点
1. **易错点**：把治理和管理当成一回事，认为"治理就是高层管理" → **正解**：治理关注方向、授权、监督与问责，主体是股东会、董事会、监事会；管理关注计划、组织、领导、控制，主体是经理层与项目经理。
2. **易错点**：把"成本领先战略"归到公司层战略 → **正解**：成本领先、差异化、集中化是波特的三种基本竞争战略，属**业务层**；公司层解决的是"做哪些业务、资源怎么分"。
3. **易错点**：认为战略管理就是"定个目标写份规划" → **正解**：战略管理是**分析—制定—实施—评价控制**的闭环，实施要靠年度计划、预算、组织调整与项目组合落地，评价控制要跟踪纠偏。
4. **易错点**：认为组织文化就是标语、口号、团建活动 → **正解**：这些是**物质层**的最表层表现；文化的核心是**精神层**的价值观，落地靠**制度层**的规则与考核。
5. **易错点**：把变革失败归因于"员工不接受新事物" → **正解**：多数是解冻不足（紧迫感没建立）、关键人未参与、缺培训支持、再冻结缺失（没固化进制度和考核）。

## ⑤ 参考答案与解析
**答案速查**：1.B　2.C　3.B　4.B　5.B　6.A　7.C　8.A

**1. B**　解析：治理确定方向并监督问责，管理负责资源组织与执行落地，B 正确。A 把两者割裂，治理贯穿组织但核心在最高层；C 说反了，治理是"做正确的事"、管理是"把事做正确"；D 编制项目管理计划属执行层面的管理活动。

**2. C**　解析：监事会是监督机构，监督董事与高管履职。A 股东（大）会是最高权力机构；B 董事会是决策机构；D 经理层是执行机构。

**3. B**　解析：面向特定市场以低价取胜，属业务层竞争战略中的成本领先（结合集中化）。A 公司层解决业务组合；C 职能层是研发、营销等职能配套；D 与战略层次无关。

**4. B**　解析：先分析环境与自身条件，再制定与选择战略，然后实施，最后评价与控制。A、C、D 都把分析或制定放错了位置，实施不可能先于方案形成。

**5. B**　解析：标语与环境属物质层，考核办法属制度层，考核导向与宣称的价值观相反，说明精神层未通过制度层落地。A 错在"文化已形成"；C 错在否认精神层为核心；D 与变革阶段无关。

**6. A**　解析：先解冻（建立紧迫感、松动旧格局），再变革（新做法落地），最后再冻结（固化防反弹）。其余选项顺序错误。

**7. C**　解析：决定进入或退出哪些业务、资源如何在业务间分配，属公司层总体战略。A 职能层是职能配套；B 业务层是"在某个业务里怎么赢"；D 属执行层面的资源平衡，不是战略层次的划分。

**8. A**　解析：公司层定总体目标，业务层定竞争策略，职能层定配套举措，逐层分解支撑，A 正确。B 错在"替代"；C 错在"独立制定"，职能层必须承接上层；D 题干描述的是战略实施中的目标分解，不是评价控制。

**判断改错题参考答案**

（1）**错误**。治理与管理不是同一概念：治理关注**方向、授权、监督与问责**，主体是股东（大）会、董事会、监事会；管理关注**计划、组织、领导、控制**，主体是经理层及项目经理。

（2）**正确**。监事会是治理结构中的**监督机构**，对董事、高级管理人员履职情况进行监督。

（3）**错误**。差异化与集中化属**业务层（竞争战略）**；公司层战略解决的是**做哪些业务、资源如何分配**。

（4）**错误**。组织文化的核心是**精神层**（使命、愿景、价值观），物质层只是最表层的表现形式。

（5）**正确**。再冻结就是通过制度、流程、考核把新做法**固化**下来，防止回到旧习惯。
