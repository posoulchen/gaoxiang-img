## ② 核心知识精讲
### 2.1 风险的定义：不确定性 + 影响，两个要素缺一不可
风险是一种**不确定的事件或条件**，一旦发生，会对项目目标（范围、进度、成本、质量）产生**正面或负面**的影响。

把定义拆成两个要素，判断就有了标尺：

- **不确定性**：它还没发生，会不会发生、什么时候发生、后果多大，都不确定；
- **影响**：一旦发生，会动到项目的目标——多花钱、拖工期、掉质量、改范围。

两个要素缺一个都不算风险。**确定会发生的事**是问题或事实，不是风险；**发生了也毫无影响的事**，不值得进风险登记册。

还有一句必须刻进脑子：**风险不等于坏事**。能带来收益的不确定性同样是风险，叫机会；会带来损失的是威胁。所以风险管理从来不是"消灭风险"，而是**提高正面风险的概率与影响、降低负面风险的概率与影响**。

### 2.2 风险与问题：一条时间线，两个本子
| 对比项 | 风险 | 问题 |
|---|---|---|
| 时间状态 | 尚未发生，可能发生 | 已经发生，正在产生影响 |
| 记录载体 | 风险登记册 | 问题日志 |
| 处理方式 | 规划并实施风险应对 | 分析原因、制定并执行解决方案 |
| 资源来源 | 应急储备/管理储备 | 项目预算与人力，必要时变更 |

一句话：**风险在前，问题在后**。案例题里如果写"某风险已经发生并造成延期"，正确答法是：该风险已转化为问题，应记入**问题日志**按问题处理，同时执行**应急应对计划**或采取**权变措施**，并评估是否需要动用**应急储备**。继续把它当"风险"挂着，就是没读懂题意。

再补一个易混点：**单个项目风险**是具体的、可登记、可单独安排应对的事件；**整体项目风险**是项目整体不确定性带来的综合影响，包含所有来源的正面与负面不确定性，也包括风险之间的相互作用。整体风险不等于单个风险简单相加，也不能靠"处理掉某一个风险"消除，得靠储备、灵活度和适应能力。

### 2.3 风险的三条属性
| 属性 | 含义 | 考场识别信号 |
|---|---|---|
| 随机性 | 是否发生、何时何地发生、后果多大都具有偶然性 | "无法准确预知""可能" |
| 相对性 | 同一风险对不同组织、不同项目影响不同 | "对 A 公司致命、对 B 公司可控" |
| 可变性 | 风险在一定条件下会增强、减弱或转化 | "随方案成熟而下降""风险变成机会" |

随机性决定了我们要用概率思维，不能靠拍脑袋断定"不会出事"；相对性决定了风险应对必须结合本组织的承受能力，别人的经验不能照搬；可变性决定了风险管理是**持续**的，识别一次就锁进抽屉的做法一定错。

### 2.4 风险分类：三个维度看全
| 分类维度 | 类型 | 要点 |
|---|---|---|
| 按后果 | 纯粹风险 / 投机风险 | 只有损失可能是纯粹风险；可能损失也可能获利是投机风险 |
| 按来源 | 外部风险 / 内部风险 | 政策、市场、自然、供应链属外部；技术、管理、资源属内部 |
| 按认知程度 | 已知风险 / 未知风险 | 可识别可分析的是已知风险；未知-未知只能用管理储备兜底 |

此外还可以按影响的目标分为范围风险、进度风险、成本风险、质量风险；按可管理性分为可管理风险与不可管理风险（如重大自然灾害、政策突变，只能承受或转移）。

分类不是背名词，是为了选对策：纯粹风险优先**规避、转移、减轻**；投机风险可以考虑**开拓、分享、提高**。这条线明天讲应对策略时还会用到。

### 2.5 风险态度：偏好、厌恶、中立
- **风险偏好**：组织或个人**愿意承担**的风险种类与数量，是为追求收益而愿意接受的不确定性程度；
- **风险厌恶**：不愿承担不确定性，倾向规避风险；
- **风险中立**：既不偏好也不厌恶，按期望值做决策。

另外两个词常被拿来混淆，顺手分清：**风险承受力**是"能承受多大"（能力），**风险临界值**是"超过多少就不接受"（度量线）。偏好讲意愿，承受力讲能力，临界值讲红线。

态度直接影响策略选择：同样的技术选型风险，风险偏好的组织可能选择"接受"甚至主动"开拓"机会；风险厌恶的组织更倾向"规避"或"转移"给供应商。

### 2.6 风险成本与两笔储备：这是必考的计算点
**风险成本**是为应对风险付出的全部代价：预防成本、应对成本、风险发生后的损失，以及为风险预留的储备。

两笔储备的分工，用"已知-未知 / 未知-未知"一刀切开：

| 储备类型 | 应对什么 | 归属与动用权限 |
|---|---|---|
| 应急储备 | 已识别风险（已知-未知） | 含在成本基准与进度基准内，项目经理在授权范围内动用 |
| 管理储备 | 未识别风险（未知-未知） | 不含在成本基准内，属项目总预算，动用需高层批准 |

两条公式要背死：

> 成本基准 = 各活动成本估算 + 应急储备
> 项目总预算 = 成本基准 + 管理储备

> 微型算例：成本基准 800 万元（内含应急储备 50 万元），管理储备 40 万元，则项目总预算 = 800 + 40 = **840 万元**。

命题人常在这里挖坑：把管理储备算进成本基准、把应急储备说成"需高层批准"、或者问"成本基准是多少"却给了总预算。看到数字先把三样东西分开摆：估算、应急储备、管理储备。

最后把风险管理七个过程的全景先挂上：**规划风险管理 → 识别风险 → 实施定性风险分析 → 实施定量风险分析 → 规划风险应对 → 实施风险应对 → 监督风险**。一句话串起来：定规则、找风险、排优先级、算影响、定对策、落对策、盯变化。

> **记忆抓手**：风险 = 不确定 + 影响，机会威胁都算；未发生进风险册，已发生进问题日志；已知-未知用应急储备（基准内、项目经理动），未知-未知用管理储备（基准外、高层批）。

## ③ 高频易错点
1. **易错点**：认为风险只会带来损失，风险管理就是消灭风险 → **正解**：风险包括威胁与机会，管理目标是降低负面风险的概率与影响、提高正面风险的概率与影响，而非消灭。
2. **易错点**：风险已经发生并造成影响，仍留在风险登记册里跟踪 → **正解**：应作为**问题**记入问题日志按问题处理，同时执行**应急应对计划**或采取**权变措施**。
3. **易错点**：认为管理储备可以由项目经理直接动用 → **正解**：应急储备含在成本基准内，项目经理在授权范围内动用；**管理储备**在成本基准之外，动用需**高层批准**，通常还要变更成本基准。
4. **易错点**：把风险偏好说成"能承受的最大风险程度" → **正解**：那是**风险承受力**；风险偏好是**愿意承担**的风险种类与数量，讲的是意愿。
5. **易错点**：认为整体项目风险就是各单个风险之和 → **正解**：整体风险还包括风险间的相互作用与未知-未知的不确定性，不等于简单加总。

**判断改错题（5 小题，每题 2 分，共 10 分）**：判断下列说法是否正确，错误的请改正。

（1）风险只会给项目带来损失，因此风险管理的目标就是消灭风险。

（2）已经发生并造成影响的风险事件，应继续留在风险登记册中跟踪，不必转入问题日志。

（3）应急储备包含在成本基准中，用于应对已识别风险，项目经理可在授权范围内动用。

（4）风险偏好是指组织能够承受的最大风险程度。

（5）整体项目风险等于各单个项目风险的简单加总。

## ⑤ 参考答案与解析
**答案速查**：1.B　2.B　3.B　4.C　5.B　6.B　7.C　8.B

**1. B**　解析：风险是不确定的事件或条件，发生后对项目目标产生正面或负面影响。A 描述的是问题；C 曲解了管理目标，风险无法也不必彻底消灭；D 只覆盖成本一个方面，且忽略了不确定性与正面影响。

**2. B**　解析：风险已发生即转化为问题，应记入问题日志按问题处理，并执行应急应对计划或权变措施。A 混淆风险与问题；C 管理储备应对未识别风险且需高层批准；D 未经变更控制直接改基准属违规。

**3. B**　解析：同一风险对不同组织影响不同，是相对性。A 强调发生与否的偶然；C 强调风险本身的变化转化；D 不是本题三条属性中的考点。

**4. C**　解析：风险随条件变化而增强、减弱或转化，是可变性。A 讲偶然性；B 讲对不同主体影响不同；D 与题干无关。

**5. B**　解析：只有损失可能、无获利可能的是纯粹风险。A 投机风险可能获利也可能损失；C 整体项目风险是综合不确定性；D 是按认知程度的分类，与"是否只有损失"不是同一维度。

**6. B**　解析：应急储备应对已识别风险，含在成本基准内，项目经理在授权范围内动用。A 管理储备应对未识别风险、在基准外、需高层批准；C、D 是臆造名称。

**7. C**　解析：风险偏好是愿意承担的风险种类与数量。A 承受力是能承受的最大程度；B 临界值是判定是否可接受的度量；D 厌恶是不愿承担风险。

**8. B**　解析：项目总预算 = 成本基准 + 管理储备 = 800 + 40 = 840 万元。A 漏了管理储备；C 误把应急储备再加一次；D 重复计算了应急储备与管理储备。

**判断改错题参考答案**

（1）**错误**。风险包含威胁与机会，既有负面影响也有正面影响；风险管理目标是**降低负面风险的概率与影响、提高正面风险的概率与影响**，而不是消灭风险。

（2）**错误**。风险一旦发生即成为**问题**，应记入**问题日志**按问题处理，同时执行**应急应对计划**或采取**权变措施**，并评估储备动用。

（3）**正确**。应急储备用于应对**已识别风险**（已知-未知），包含在**成本基准**内，由项目经理在授权范围内动用。

（4）**错误**。风险偏好是**愿意承担**的风险种类与数量；"能够承受的最大风险程度"是**风险承受力**，两者一个讲意愿、一个讲能力。

（5）**错误**。整体项目风险还包含风险之间的**相互作用**以及**未知-未知**的不确定性，不等于各单个风险的简单加总。
