## ② 核心知识精讲
### 2.1 五级标准体系：谁制定、谁必须执行
《标准化法》把标准分为五级：**国家标准、行业标准、地方标准、团体标准、企业标准**。这个顺序不是随便排的，它对应着适用范围从广到窄、制定主体从政府到市场。

国家标准分为**强制性标准**和**推荐性标准**；**行业标准、地方标准是推荐性标准**；团体标准、企业标准由市场自主制定。**强制性标准必须执行**，推荐性标准国家鼓励采用。

制定主体要分清：国家标准由国务院标准化行政主管部门制定；行业标准由国务院有关行政主管部门制定，并报国务院标准化行政主管部门备案；地方标准由省、自治区、直辖市人民政府标准化行政主管部门制定，设区的市级人民政府标准化行政主管部门也可以制定本行政区域的地方标准；团体标准由学会、协会、商会、联合会、产业技术联盟等社会团体协调相关市场主体共同制定；企业标准由企业自行制定。

效力关系上有一条硬杠杠：**推荐性国家标准、行业标准、地方标准、团体标准、企业标准的技术要求，不得低于强制性国家标准的相关技术要求**。国家鼓励社会团体、企业制定高于推荐性标准相关技术要求的团体标准、企业标准。

还有两个容易忽略的点：标准的**复审周期一般不超过 5 年**；**强制性标准文本应当免费向社会公开**，国家推动免费公开推荐性标准文本。

| 标准层级 | 代号示例 | 性质与制定主体 |
|---|---|---|
| 国家标准 | GB、GB/T、GB/Z | 强制性/推荐性/指导性技术文件，国务院标准化行政主管部门 |
| 行业标准 | SJ/T、YD/T、JR/T | 推荐性，国务院有关行政主管部门 |
| 地方标准 | DB11/T、DB31/T | 推荐性，省级或设区的市级标准化行政主管部门 |
| 团体标准 | T/XXX | 市场自主制定，社会团体 |
| 企业标准 | Q/XXX | 市场自主制定，企业 |

> **记忆抓手**：**"GB 强制、GB/T 推荐、GB/Z 指导；DB 地方、T 团体、Q 企业"**。看到斜杠后面带 T 的，基本都是推荐性；看到 GB 后面直接跟数字的，就是强制性国标。

### 2.2 信息系统常用标准：一个标准号对应一个场景
系统集成项目里常用的标准不多，但每一个都可能出现在选择题的选项里。按"文档—质量—安全—过程—服务"五条线记：

| 标准号 | 名称 | 典型用途 |
|---|---|---|
| GB/T 8567 | 计算机软件文档编制规范 | 规定软件文档种类与编制要求，如需求规格说明、设计说明书、测试报告 |
| GB/T 8566 | 信息技术 软件生存周期过程 | 把生存周期过程分为基本过程、支持过程、组织过程 |
| GB/T 19001 | 质量管理体系 要求 | 等同采用 ISO 9001，用于建立和认证质量管理体系 |
| GB/T 22239 | 信息安全技术 网络安全等级保护基本要求 | 等级保护 2.0 的核心标准，按五个安全保护等级提出要求 |
| GB/T 20984 | 信息安全技术 信息安全风险评估方法 | 指导资产、威胁、脆弱性识别与风险计算 |
| GB/T 28827.1 | 信息技术服务 运行维护 通用要求 | ITSS 运维服务能力的基础标准 |
| GB 50174 | 数据中心设计规范 | 机房选址、布局、环境、电气等设计依据 |

GB/T 8567 规定的主要文档包括：可行性研究报告、项目开发计划、软件需求规格说明、概要设计说明书、详细设计说明书、数据库设计说明书、测试计划、测试报告、用户手册、操作手册、开发进度月报、项目开发总结报告。案例里凡是出现"只交了用户手册""没有需求规格说明""测试报告缺失"，都往 GB/T 8567 上靠。

GB/T 19001 采用七项质量管理原则：以顾客为关注焦点、领导作用、全员积极参与、过程方法、改进、循证决策、关系管理。这七项和教材质量管理章节是同一套语言，选择题常把"以顾客为关注焦点"换成"以产品为中心"来设错。

GB/T 22239 对应的等级保护分五级：第一级自主保护、第二级指导保护、第三级监督保护、第四级强制保护、第五级专控保护。等级由**网络运营者自主确定**，第二级以上要到公安机关**备案**；第三级系统**每年至少测评一次**，第四级**每半年至少一次**。

> **记忆抓手**：**"8567 管文档、19001 管质量、22239 管等保、8566 管过程、28827 管运维"**。五个标准号配五个动词，考场上先想动词再选标准。

### 2.3 系统集成资质与项目经理：行政审批退了，行业评价上了
这一块考生最容易用旧知识答题。2014 年起，计算机信息系统集成企业资质认定等行政审批事项被取消，资质不再由政府审批发证，转而由**行业组织**开展信息系统建设和服务能力评估，按能力成熟度分级。也就是说：**"系统集成资质"不再是行政审批，而是行业自律性评价**，投标时招标文件仍可把它作为能力证明，但它不是行政许可。

涉密信息系统集成资质是例外，它由国家保密行政管理部门审查认定，分甲级、乙级，承担不同密级的涉密项目。这个属于保密管理范畴，和普通的系统集成资质不是一回事。

项目经理这一端，**信息系统项目管理师**属于计算机技术与软件专业技术资格（水平）考试的高级资格，通过考试即取得相应资格，用人单位可根据需要聘任相应专业技术职务。它不是"执业资格"，也不是"注册制"，而是**职业资格**。案例里如果写"项目经理持有系统集成项目管理工程师证书即可担任高级项目经理"，这种把资格等级与岗位等级直接画等号的表述，往往就是命题人埋的错。

ITSS 的运维服务能力成熟度分四级，**一级为最高级**；CMMI 成熟度分五级，**五级为最高级**。两个"级"的方向相反，这是常见的偷换点。

### 2.4 标准在案例里怎么用：三步定位
第一步，看场景关键词：文档、质量、安全、运维、机房，分别对应 8567、19001、22239、28827.1、50174。第二步，看约束来源：法律法规引用、合同约定、招标文件要求，只要被引用，推荐性标准就变成**必须执行**。第三步，看不符合的后果：文档缺失、测评未做、体系未运行，都是"过程不符合标准"，要写整改措施而不是只写"加强管理"。

答标准类案例，话术就三句：**应执行什么标准**（标准号加名称）、**现状不符合哪条要求**（具体缺什么）、**整改怎么做**（补文档、做测评、建体系、修订企业标准）。

## ③ 高频易错点
1. **易错点**：认为推荐性标准可做可不做，项目里不执行也没关系 → **正解**：推荐性标准本身是自愿采用，但**一经法律法规引用、合同约定或招标文件要求，就对当事人产生约束力，必须执行**。
2. **易错点**：把行业标准、地方标准也当成强制性的 → **正解**：国家标准才分强制性和推荐性；**行业标准、地方标准都是推荐性标准**；强制性标准必须执行。
3. **易错点**：看到 GB/T 就以为比 GB 高级 → **正解**：GB 是强制性国家标准，GB/T 是推荐性国家标准，二者是性质之分，不是级别高低；GB/Z 是国家标准化指导性技术文件。
4. **易错点**：认为标准可以一直用，不需要复审 → **正解**：标准的复审周期一般**不超过 5 年**，复审后分别作出继续有效、修订或废止的处理。
5. **易错点**：把系统集成资质还当成政府审批，或把 ITSS 与 CMMI 的"级"记反 → **正解**：系统集成资质认定已取消行政审批，转为**行业组织评价**（涉密资质由保密部门审查，分甲级、乙级）；ITSS 运维服务能力成熟度**一级最高**，CMMI 成熟度**五级最高**。

**二、案例小问（1 题）**

【背景】某市建设政务云平台，预算 3000 万元，承载全市政务数据。招标文件明确要求：软件文档编制执行 GB/T 8567，信息安全执行 GB/T 22239 第三级要求，承建方应建立符合 GB/T 19001 的质量管理体系。承建方 A 公司中标后，仅在验收前提交了用户手册和操作手册；安全方案按第二级设计，未开展等级测评；质量管理体系文件直接照搬三年前的旧版，与本项目实际流程不符；A 公司还自行发布了一项企业标准，其中部分技术指标低于对应的强制性国家标准。

【问题1】请指出 A 公司在标准执行方面的不妥之处，并说明应执行的标准依据。（6 分）
【问题2】政务云平台的网络安全保护等级应如何确定？第三级系统在测评与备案上有何要求？（4 分）

## ⑤ 参考答案与解析
**答案速查**：1.C　2.B　3.B　4.B　5.A　6.B　7.B　8.C

**1. C**　解析：国家标准分强制性和推荐性，行业标准、地方标准都是推荐性标准。A、B 把行业标准、地方标准说成可分强制性，错误；D 团体标准由社会团体制定，不是国务院标准化行政主管部门。

**2. B**　解析：GB/T 中"T"表示推荐性，GB/T 22239 是推荐性国家标准。A 强制性国标代号是 GB；C 指导性技术文件代号是 GB/Z；D 行业标准代号如 SJ/T、YD/T。

**3. B**　解析：标准的复审周期一般不超过 5 年，复审后作出继续有效、修订或废止的处理。3 年、8 年、10 年均无法定依据。

**4. B**　解析：GB/T 8567 是计算机软件文档编制规范，规定的正是需求规格说明、设计说明书、测试报告等文档种类与编制要求。A 是软件生存周期过程；C 是质量管理体系；D 是运维服务通用要求。

**5. A**　解析：GB/T 22239 是网络安全等级保护基本要求。B 是风险评估方法；C 是数据中心设计规范；D 是信息技术安全性评估准则。

**6. B**　解析：GB/T 19001 等同采用 ISO 9001，是质量管理体系标准，属于推荐性国家标准。A 说成强制性、必须认证，错误；C 是 GB/T 8567 的内容；D 是 GB/T 22239 的内容。

**7. B**　解析：推荐性标准自愿采用，但一经合同约定或招标文件引用，即对当事人产生约束力，必须执行。A、D 忽略了引用产生的约束力；C 混淆了"推荐性"与"可否约定执行"。

**8. C**　解析：系统集成资质认定已取消行政审批，转为行业组织评价。A 是旧知识；B 信息系统项目管理师是职业资格，不是执业资格、不实行注册；D 涉密信息系统集成资质由保密行政管理部门审查认定。

**案例参考答案要点**

**问题1（6 分，每点 1.5 分，答出 4 点即可）**

- **文档提交不全**：仅提交用户手册和操作手册，缺少可行性研究报告、软件需求规格说明、概要设计说明书、详细设计说明书、测试计划、测试报告等。依据 **GB/T 8567**，应按规定的文档种类和编制要求交付全套文档。（1.5 分）
- **安全等级设计偏低**：承载全市政务数据，招标文件已明确要求第三级，A 公司按第二级设计不符合要求。依据 **GB/T 22239**，应按第三级基本要求设计并落实安全措施。（1.5 分）
- **未开展等级测评**：第三级系统上线运行前应进行等级测评，运行中每年至少测评一次。A 公司未测评即申请验收，不符合要求。（1.5 分）
- **质量管理体系未落地**：照搬旧版体系文件、与本项目流程不符。依据 **GB/T 19001**，应建立并有效运行与项目实际相适应的质量管理体系，保留相应记录。（1.5 分）
- **企业标准低于强制性国家标准**：企业标准的技术要求不得低于强制性国家标准的相关技术要求，A 公司自行发布的企业标准部分指标偏低，必须修订。（1.5 分）

**问题2（4 分）**

- 网络安全保护等级由**网络运营者**根据网络的功能、服务范围、数据重要性等**自主确定**，并按规定报公安机关**备案**；第二级以上网络应在等级确定后到公安机关办理备案手续。（2 分）
- 第三级系统应当**每年至少进行一次等级测评**，测评由具备相应资质的测评机构实施；系统上线运行前也应完成等级测评，不符合的应整改后再运行。（2 分）

**问题3（3 分）**

- GB/T 8567 是**推荐性国家标准**，本身不具有强制执行力，国家鼓励采用。（1 分）
- 但招标文件已明确引用该标准，属于当事人**约定采用**；标准一经合同、招标文件引用，即对当事人产生**约束力**，A 公司必须执行，否则构成违约，验收时招标人有权要求整改。（2 分）
