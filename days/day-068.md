## ② 核心知识精讲
### 2.1 这类题到底考什么：四个筐，别乱装

项目管理科学基础在考试里就几个筐：**线性规划、图论（最短路径/最小生成树）、网络计划与资源分配**，后面还有决策论、排队论、存储论。它们的共同点是：题面用项目管理的话讲，解法却是标准的数学模型。

考场上的正确姿势是**先分筐、再套步骤**，不要一上来就列方程。给一张表对比着记：

| 题型 | 识别信号 | 解法关键词 |
|---|---|---|
| 线性规划 | 两种资源、两个产品、求最大利润/最小成本 | 建模 + 图解法找顶点 |
| 最短路径 | 网络图、求两点间最短距离/最快时间 | Dijkstra 逐点标号 |
| 最小生成树 | 连通所有节点、总代价最小、不能成圈 | Prim 或 Kruskal |
| 资源优化 | 资源峰值过高、要削峰 | 资源平衡 / 资源平滑 |

这四类题都有"标准动作"，练熟之后基本是送分。反过来，最忌讳的是凭感觉猜——命题人给的四个选项往往就是几个典型错算结果。

### 2.2 线性规划：三件套建模，四个顶点定答案

**建模三件套**，一个都不能少：

- **决策变量**：你要决定什么？设甲生产 x 件、乙生产 y 件；
- **目标函数**：你要最大化或最小化什么？如 max z = 3x + 2y；
- **约束条件**：资源、产能、需求上限，如 2x + y ≤ 10。

另外别忘了**非负约束** x ≥ 0、y ≥ 0——这是最容易漏写、也最容易被扣分的一条。

**图解法的四步**，请按顺序走：

1. 把每个约束当等式画直线；
2. 用原点或任一点代入不等式，定出**可行域**（所有约束同时满足的区域）；
3. 令目标函数等于某个方便的值，画一条**等值线**；
4. 沿目标函数增大的方向平移等值线，**最后离开可行域的那个顶点就是最优解**。

结论要背死：**若线性规划有最优解，最优解一定可以在可行域的某个顶点（角点）上取得**。所以考试时根本不用求内部点，把可行域的角点坐标算出来，逐个代进目标函数比大小即可。

> **微型算例**：max z = 3x + 2y，约束 x + y ≤ 4，x ≤ 2，x、y ≥ 0。可行域顶点为 (0,0)、(2,0)、(2,2)、(0,4)，代入得 z = 0、6、10、8，最优解 (2,2)，**z = 10**。

考场提醒：求**最小值**时平移方向相反；算出的顶点如果不是整数而题目要求整件数，要在可行域内就近取整并重新检查约束是否满足——命题人挖坑常在这里。

### 2.3 图论：最短路径与最小生成树，一字之差两种活

先分清这两件事，很多考生栽在读题上：

- **最短路径**：从**一个点到另一个点**，走哪条路总长度最短。只关心这两点之间的路，其他点可以绕开。
- **最小生成树**：用若干条边把**所有点连通**，且总权值最小、不能形成圈。关心的是"全都连上"的代价。

| 问题 | 常用方法 | 判断要点 |
|---|---|---|
| 最短路径 | Dijkstra（迪杰斯特拉） | 每次选距离最小的未确定点，确定后不再改 |
| 最小生成树 | Prim（普里姆） | 从一点出发，每次选连接"已选点集"与"未选点集"的最小边 |
| 最小生成树 | Kruskal（克鲁斯卡尔） | 全部边从小到大排序，逐条选入，成圈就跳过 |

**Dijkstra 的执行口诀**：给起点标 0，其余标无穷；每轮从未确定的点里挑**当前距离最小**的那个，把它确定下来，再用它去"松弛"邻居（邻居距离 = min(原距离, 当前点距离 + 边长)）；重复到目标点被确定。它要求**边权非负**，有负权边就不能用。

**Prim 与 Kruskal 的区别**，一句话：Prim **从点长边**（长出一棵树），Kruskal **排边避圈**（先选最小边，再看会不会成圈）。两者结果的总权值相同，但选边的中间过程不同。考试若让"写出选边顺序"，一定要看清题目指定的是哪种算法。

> **微型算例**：A—B 权 3，A—C 权 6，B—C 权 2，B—D 权 5，C—D 权 4。A 到 D 最短路为 A→B→D = 3 + 5 = **8**（A→B→C→D 为 9，A→C→D 为 10）；该网络最小生成树选 B—C(2)、A—B(3)、C—D(4)，总权值 = **9**。

注意算例里最短路是 8、生成树是 9，两个数只差 1——命题人特别喜欢用这种接近的数字做干扰项，你必须清楚自己算的是哪一种。

### 2.4 网络计划与资源分配：既考算法也考概念

**关键路径法**是进度管理的老朋友，这里只做复习式提醒：正推算 ES、EF（EF = ES + 工期），逆推算 LS、LF（LS = LF − 工期）；**总时差 = LS − ES = LF − EF**，总时差为 0 的活动在关键路径上，关键路径决定项目总工期。

考试在资源这一块最爱考的是两个概念的区别：

- **资源平衡**：为了在资源供应限制下安排活动，可能把活动移到非关键时段，**往往会改变关键路径、可能延长总工期**；
- **资源平滑**：只在活动的**自由时差/总时差范围内**调整，削掉资源需求的峰值，**不改变关键路径，也不延长总工期**。

一句话记：**平衡会动工期，平滑不动工期**。题目里出现"不允许影响总工期，只把资源峰值压下来"，答案只能是资源平滑；出现"某关键资源只有 2 个人，必须按人排计划"，才考虑资源平衡。

网络计划的另一类考法是"工期—资源优化"：在工期不变的前提下调整非关键活动的开始时间，使资源需求曲线尽量平缓。做法就是找时差、挪活动、看峰值，不涉及复杂计算。

### 2.5 运筹学在项目管理里怎么用：会翻译就赢一半

这些模型不是数学系的东西，它在项目管理里有明确落点：

- 线性规划 → 多产品产量组合、有限资源下的任务分派、自制或外购的数量决策；
- 最短路径 → 物流与布线、数据同步链路、关键链上的最短联通方案；
- 最小生成树 → 网络布线、园区管网、多分支机构的专线组网，用最低总代价连通所有节点；
- 网络计划与资源优化 → 工期与资源的权衡、赶工方案比选。

考场上遇到这类题，第一步永远是**把业务话翻译成数学话**：谁是变量、什么是上限、要最大化还是最小化。翻译对了，后面就是套步骤；翻译错了，算得再快也是错。

> **记忆抓手**：线性规划"变量—目标—约束"三件套，最优必在角点；最短路看 Dijkstra"挑最小、定了不改"；生成树 Prim 从点长、Kruskal 排边避圈；资源平衡动工期，资源平滑不动工期。

## ③ 高频易错点
1. **易错点**：建模时只写目标函数和资源约束，漏掉非负约束 → **正解**：决策变量代表数量、人数、件数，必须有 x ≥ 0、y ≥ 0，否则可行域会扩到负半轴，最优解直接跑偏。
2. **易错点**：以为最优解可能出现在可行域内部，于是去解方程组找内点 → **正解**：线性规划若存在最优解，必可在可行域的**顶点**取得，逐个比较角点即可。
3. **易错点**：把最短路径与最小生成树混着算，题目要"连通所有点"却去求两点最短路 → **正解**：先看题眼——"A 到 D 最短"是最短路径；"连通全部节点、总代价最小"是最小生成树。
4. **易错点**：用 Dijkstra 处理带负权边的图 → **正解**：Dijkstra 要求**边权非负**，存在负权边时该方法不适用。
5. **易错点**：认为资源平滑也会延长工期，或认为资源平衡不影响关键路径 → **正解**：资源平滑只在时差内调整，**不改变关键路径、不延长工期**；资源平衡可能改变关键路径并**延长工期**。

**二、案例小问（1 题）**

【背景】某软件公司承接一个平台建设项目，需自行开发甲、乙两类功能模块。公司每周可投入开发人员 10 人周、测试人员 8 人周。单个甲模块需开发 2 人周、测试 1 人周，可获利润 3 万元；单个乙模块需开发 1 人周、测试 2 人周，可获利润 2 万元。两类模块的市场需求均不受限制，公司要求给出利润最大化的开发组合。

【问题1】请建立该问题的线性规划模型（含决策变量、目标函数、约束条件）。（4 分）
【问题2】用图解法求出最优开发组合与最大利润。（6 分）
【问题3】若市场对甲模块的需求不超过 3 个，最优组合与最大利润如何变化？（4 分）

## ⑤ 参考答案与解析
**答案速查**：1.A　2.B　3.C　4.B　5.A　6.B　7.A　8.D

**1. A**　解析：线性规划模型由决策变量、目标函数、约束条件（含非负约束）构成。B 含概率与损益值，是风险型决策的要素；C 是决策论中状态集与方案的表述；D 描述的是不确定型决策。

**2. B**　解析：线性规划若存在最优解，必可在可行域的顶点取得（可能整条边同为最优，但必含顶点）。A 内部点不是线性目标函数的极值点；C、D 只是特殊位置，不能作为一般结论。

**3. C**　解析：max z = 3x + 2y，x + y ≤ 4，x ≤ 2，x、y ≥ 0。顶点 (0,0)=0、(2,0)=6、(2,2)=10、(0,4)=8，最大为 10 万元。A 只算了甲 2 件（丢掉了乙的贡献）；B 只算了乙 4 件；D 让甲取 4 件，违反设备数量约束。

**4. B**　解析：A→B→D = 3 + 5 = 8；A→B→C→D = 3 + 2 + 4 = 9；A→C→D = 6 + 4 = 10。最短为 8。C 是很多人把生成树结果当成最短路的误答。

**5. A**　解析：Dijkstra 依赖"已确定点的距离不会再被更短路径超越"这一性质，要求边权非负。B、C 不是必要条件，含回路的图同样可用；D 无此要求，算法求出的是源点到所有点的最短距离。

**6. B**　解析：按边权从小到大选 B—C(2)、A—B(3)、C—D(4)，三边连通 A、B、C、D 且不成圈，总权值 2 + 3 + 4 = 9。A 漏选一条边导致节点不连通；C 用 B—D(5) 替代 C—D(4)，总权 10，不是最小；D 把 A—C(6) 也选入，A、B、C 之间成圈，不构成生成树。

**7. A**　解析：Prim 是"加点"式生长，每次选连接已选点集与未选点集的最小边；Kruskal 是"选边"式，全局排序后避圈选取。B 把两者说反；C 无向图即可；D 两者求出的最小生成树总权值相同（树可能不唯一，但总权值一致）。

**8. D**　解析：资源平滑在时差范围内调整，不改变关键路径、不延长总工期；资源平衡为满足资源限制可能调整关键活动，从而改变关键路径并延长工期。A 把两者混同；B、C 与定义相反。

**案例参考答案要点**

**问题1（4 分）**

设甲模块开发 x 个、乙模块开发 y 个。（**决策变量**，1 分）

目标函数：max z = 3x + 2y（**目标函数**，1 分）

约束条件：2x + y ≤ 10（开发人员）；x + 2y ≤ 8（测试人员）；x ≥ 0，y ≥ 0（**非负约束**，2 分，漏非负约束扣 1 分）

**问题2（6 分）**

可行域顶点为 (0,0)、(5,0)、(0,4) 以及两约束直线的交点 (4,2)。（列出顶点 3 分）

代入目标函数：z(0,0) = 0；z(5,0) = 15；z(0,4) = 8；z(4,2) = 3×4 + 2×2 = 16。（计算 2 分）

**最优解为 x = 4、y = 2，最大利润 16 万元**。（结论 1 分）

**问题3（4 分）**

增加约束 x ≤ 3 后，可行域收缩。当 x = 3 时，y 的上限为 min(10 − 6, (8 − 3)/2) = min(4, 2.5)，取整后 y = 2，此时 2×3 + 2 = 8 ≤ 10、3 + 4 = 7 ≤ 8，约束均满足，z = 3×3 + 2×2 = **13 万元**。（3 分）

对比原最优解 16 万元，最大利润下降 3 万元，**最优组合变为甲 3 个、乙 2 个**。（1 分）
