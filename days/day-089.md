## ② 核心知识精讲
### 2.1 先看清卷面：三类题，三种答法
案例卷 3 道大题，每道大题下挂 2–4 个小问。小问的题型就三类，答题结构完全不同，混着写必然丢分。

| 题型 | 典型问法 | 答题结构 |
|---|---|---|
| 找错题 | 指出不妥之处 / 存在哪些问题 | 不妥之处 + 理由 + 正确做法 |
| 原因题 | 分析……的原因 | 直接原因 + 管理原因（对应过程缺失） |
| 措施题 | 提出改进措施 / 如何避免 | 按过程顺序给动作，一条一个动词 |

找错题是最好拿分的：阅卷按条给分，一条 1–2 分，写 10 条对的就接近满分，写 3 条再漂亮也只有 6 分。所以**宁可多写两条，也别只写三条**——当然，凑数的废话不算，必须是真错。

原因题要往管理过程上靠。比如"项目延期"，直接原因是某活动返工，管理原因是没做好进度控制、没识别关键路径、没有变更控制。**命题人常在这里挖坑**：把诱因写在背景里（比如"项目经理同时负责三个项目"），你要能顺着诱因追到管理动作缺失。

措施题最忌空话。"加强沟通"四个字不值分，"制定沟通管理计划、明确例会频次与报告模板、更新干系人参与计划"才是采分点。一条措施里至少要有一个教材术语。

### 2.2 90 分钟怎么切：先计算，后文字
案例卷的时间比综合知识紧得多，90 分钟写三道大题，平均一题 30 分钟。合理的切法是：

| 时段 | 任务 | 目标 |
|---|---|---|
| 0–3 分钟 | 通读三题题干，判断哪题是计算、哪题文字量最大 | 定下做题顺序 |
| 3–30 分钟 | 先做计算题，公式、步骤、单位一次写清 | 拿到 25 分里的绝大部分 |
| 30–65 分钟 | 找错题，按条写，能写几条写几条 | 8 条以上 |
| 65–85 分钟 | 理论题 / 措施题，按过程顺序列动作 | 每条带术语 |
| 85–90 分钟 | 检查小问是否答全、编号是否连续、有无错别字 | 无漏答 |

为什么计算题必须先做？三个理由：第一，计算题答案是确定的，做对了就是满分，性价比最高；第二，文字题写到最后手会抖、脑子会钝，而计算最需要清醒；第三，一旦文字题写嗨了超时，你会连计算题的题干都没读完。

**考场上一句话**：先拿确定的分，再拿能凑的分，最后拿要磨的分。

### 2.3 三段式怎么写才像标准答案
以变更类找错为例，标准答案长这样：

- **不妥一**：客户口头提出新增功能后，项目经理直接安排开发。理由：未提出书面变更申请、未评估变更对进度成本的影响、未经变更控制委员会审批。正确做法：提交变更申请，完成影响评估，报 CCB 审批通过后实施，并更新基准与项目文件。

一行里三个要素齐全，阅卷老师扫一眼就能打勾。写成"项目经理没有走变更流程，这样做是不对的，应该按流程办事"——只有一个模糊的意思，没有理由、没有正确做法，最多给 1 分。

三段式还有个隐藏好处：它天然逼你想全。你写"不妥"的时候会问自己"哪里不妥"，写"理由"时会去找教材依据，写"正确做法"时会想起过程名——三个动作，三次回忆，采分点自然变多。

### 2.4 计算题：过程分比结果分更值钱
案例计算题基本集中在关键路径、时差、工期压缩、挣值预测这几类。写答案的铁律是：**公式 → 代入 → 结果 → 结论**，四步齐全，单位不丢。

- 总时差 = 最晚开始 − 最早开始 = 最晚完成 − 最早完成。算例：LS = 8，ES = 5，总时差 3 天。
- 自由时差 = 紧后活动最早开始 − 本活动最早完成。算例：紧后 ES = 12，本活动 EF = 9，自由时差 3 天。
- 挣值判断：CPI = EV ÷ AC，SPI = EV ÷ PV。算例：EV = 810 万元、PV = 900 万元，SPI = 0.9，进度落后 10%。

即使最后结果算错，只要公式写对、代入写清，过程分照样给。反过来，只写一个数字，错了就是 0 分——这就是为什么"会做但算错"的人，案例分总是比估分低。

> **记忆抓手**：**"一题一序：计算先行；一问三段：错、因、法；一算四步：式、代、果、论"**。这三句话背下来，案例卷的骨架就立住了。

## ③ 高频易错点
1. **易错点**：找错题只写"做法不妥"，不写理由和正确做法 → **正解**：三段式缺一段就少一半分，理由要点到教材规则，正确做法要给可执行动作。
2. **易错点**：答案写成一大段，条与条之间没有编号 → **正解**：一条一行、编号打头，机考也一样；阅卷是按条找采分点，埋在段落里等于没写。
3. **易错点**：计算题只写结果，不写公式和步骤 → **正解**：式、代、果、论四步齐全，过程分往往占该小问的一半。
4. **易错点**：按题目顺序先做文字题，计算题留到最后 → **正解**：计算题优先，文字题时间弹性大，计算题一旦仓促就全错。
5. **易错点**：措施题写"加强管理、提高认识、加强沟通" → **正解**：每条措施必须落在一个过程或一份文件上，比如"编制质量管理计划""开展质量审计""更新风险登记册"。

## ⑤ 参考答案与解析
**一、评分标准（案例卷怎么给分）**

| 题型 | 给分规则 | 自评要点 |
|---|---|---|
| 找错题 | 每条"不妥 + 理由"1–2 分，答满点数即满分，超答不扣分 | 数条数，不看字数 |
| 原因题 | 直接原因与根本原因分别给分，答到管理过程才给高分 | 是否落到过程缺失 |
| 措施题 | 每条 1 分，须含术语或文件名称，空话不给分 | 每条是否有教材词 |
| 计算题 | 公式、代入、结果、结论分段给分，结果错但过程对仍得分 | 四步是否齐全 |

每题 25 分，按小问分配到分；自评时按"该拿的分"算，不看"我写了多少字"。三题合计 75 分，45 分及格，稳定线要奔 55 分以上。

**二、复盘方法（明天精析前的准备）**

1. **只标不判**：今天只标出"该拿没拿到"的小问，不写正确答案，避免记忆污染明天的重写训练。
2. **计时复盘**：把每题的起止时间写下来，重点看文字题是否超时挤占了检查时间。
3. **对照错点清单**：把你今天漏掉的点，与 Day 088 的清单逐条对，能对上的说明清单有效，对不上的要补进清单。

**三、应用回炉答案速查**：1.B　2.A　3.D　4.C　5.A　6.C　7.D　8.B

**1. B**　解析：找错题按条给分，"不妥 + 理由 + 正确做法"三段齐全才能拿满每条分值。A 只写做法，缺"不妥"和"理由"；C 段落式书写让采分点难以定位；D 抄教材不结合背景，不构成对错误的指认。

**2. A**　解析：SPI = EV ÷ PV = 810 ÷ 900 = 0.9 < 1，进度落后。B 把小于 1 读成超前；C、D 把 PV 与 EV 位置颠倒，算成 900 ÷ 810 ≈ 1.11。

**3. D**　解析：计算题答案确定、性价比最高，且最需要清醒的头脑，应优先完成；文字题时间弹性大，可放后面。A 机械平均，遇到难题会崩；B 省掉通读，容易低估文字量；C 先跳过计算题，等于把最稳的分放到最后。

**4. C**　解析：变更必须走"提出申请—评估影响—CCB 审批—实施—验证—更新文件"的完整流程，口头提出、当场实施是典型的变更失控。A 发起人不必事事知情；B 质量审计与本情形无关；D 更新进度计划只是变更后的一个动作，不是主要不妥。

**5. A**　解析：机考作答与纸笔同理，分条编号＋术语原词是采分点能被识别的关键。B 大段文字会埋掉采分点；C 口语化表达缺少术语，往往不给分；D 只写结论等于放弃理由分。

**6. C**　解析：案例文字题按点给分，落在教材术语与具体措施上才得分，泛泛而谈等于没答。A 字数多不是问题；B 答题顺序不影响得分；D 使用教材原词恰恰是加分项。

**7. D**　解析：自评要对着采分点逐条核对，并统计扣分类型（漏点、无术语、无措施、计算失误），才能指导下一次改进。A、B、C 都是形式指标，与得分无必然关系。

**8. B**　解析：赶工与快速跟进是两种进度压缩技术，都不改变范围，前者以成本换时间，后者以风险换时间。A 是缩减范围；C 是进度计划的调整结果，不是压缩技术；D 是储备动用，与压缩工期无直接关系。
