## ② 核心知识精讲

### 2.1 信息：用来消除不确定性的东西

信息是客观事物状态和运动特征的一种普遍形式。维纳说"信息既不是物质也不是能量"，香农说"信息是能够用来消除不确定性的东西"。抓两个词：**客观存在**、**消除不确定性**。

信息的价值不在"多"，而在质量。7 条质量属性必须背下来：

| 质量属性 | 一句话抓手 | 典型场景 |
|---|---|---|
| 精确性 | 粒度够不够、数值准不准 | 库存数量精确到个位 |
| 完整性 | 该有的字段一个不少 | 客户档案缺联系电话 |
| 可靠性 | 来源可信、经得起复核 | 数据取自权威系统 |
| 及时性 | 赶不赶得上决策时点 | 日报第二天中午才出 |
| 经济性 | 获取成本不高于收益 | 为 3 个客户建大数据平台 |
| 可验证性 | 能被独立核对、有据可查 | 每笔数据有原始凭证 |
| 安全性 | 不该看的人看不到 | 薪酬数据分级授权 |

考场从不问"有哪几条"，而是给场景反推。看到"必须齐全、缺项退回"是完整性；"决策前拿到、次日 8 点前"是及时性；"逐一核对、留有凭证"是可验证性。

### 2.2 信息系统：六块拼图，缺一块转不动

信息系统是以处理信息为目的的专门系统，由 **硬件、软件、数据（信息资源）、通信网络、人员、规程** 六要素组成。

很多人只记前五个，考场上问"不包括下列哪项"时就把"规程"漏了。它必须算一块：没有人规定"谁在什么时点、按什么格式、走什么流程录入并审核数据"，硬件再贵、软件再好，数据也是脏的。**规程就是制度化的运行规则。**

"人员"也不只是操作员，它包括使用者、维护者、管理者与外部数据提供方。教材强调信息系统是**人机系统**，人是系统能否真正发挥作用的关键。

生命周期四段：**立项（规划）→ 开发（分析、设计、实施）→ 运维 → 消亡（更新改造）**。记一条判断：运维不是终点，消亡才是；系统被替换、整合、下线，都要做数据迁移与归档。

### 2.3 信息化：一个过程、五个层次、六个要素

信息化定义抓三个词：**过程**、**信息资源开发利用**、**推动发展转型**。它不是"买设备、上系统"这个动作。

五层次由小到大必须记死：产品信息化 → 企业信息化 → 产业信息化 → 国民经济信息化 → 社会生活信息化。考法就是打乱顺序让你排，或问"行业协会推动全行业设备联网协同属于哪个层次"——产业信息化。

高频点是**国家信息化体系六要素**的定位：

| 要素 | 定位 |
|---|---|
| 信息技术应用 | 龙头 |
| 信息资源 | 核心任务 |
| 信息网络 | 基础设施 |
| 信息技术和产业 | 物质基础 |
| 信息化人才 | 成功之本 |
| 信息化政策法规和标准规范 | 发展保障 |

> **记忆抓手**：应用是龙头、资源是核心、网络是基础、产业是后盾、人才是根本、法规是保障。**龙头是"用"，核心是"料"。**

考场最爱把"龙头"和"核心"互换。一句破解：没有应用，信息化就没有牵引力；没有信息资源，信息化就是空转的设备。

### 2.4 两化融合：融的是三个台阶

两化融合是信息化与工业化融合，不是"企业上 ERP、车间装大屏"。落点是：以信息化带动工业化、以工业化促进信息化，走科技含量高、经济效益好、资源消耗低、环境污染少、人力资源优势得到充分发挥的**新型工业化道路**。

三级台阶：**技术融合**（传感器、控制系统装上设备）→ **业务融合**（柔性生产、按单排产、预测性维护）→ **产业融合**（从卖设备转向卖"设备+数据服务"）。

> **记忆抓手**：两化融合走"技术—业务—产业"三级台阶；六要素戴"龙头、核心、基础、后盾、根本、保障"六顶帽子。这两句今天必须背到脱口而出。

## ③ 高频易错点

1. **易错点**：把"数据"和"信息"当同义词 → **正解**：数据是记录下来的符号（载体），信息是经加工、能减少不确定性、对决策有意义的数据；同一份数据对不同岗位价值不同，这是信息的相对性。
2. **易错点**：把及时性和精确性混着选 → **正解**：强调"能不能在决策时点前拿到"是及时性；强调"数值准不准、粒度够不够细"是精确性。
3. **易错点**：认为六要素里"信息网络"是核心 → **正解**：核心任务是**信息资源**，信息网络是**基础设施**，龙头是**信息技术应用**。命题人最爱把这三个位置打乱重排。
4. **易错点**：把"人员"只理解成操作员 → **正解**：人员含使用者、维护者、管理者及外部数据提供方；漏掉"规程"是选择题最常见的错法。
5. **易错点**：以为两化融合就是企业上 ERP → **正解**：ERP 只是一个技术动作，两化融合看的是信息技术与工业技术、业务、产业的深度结合，最终落到新型工业化道路。

**一、单选题（8 题，每题 1 分）**

1. 某市建设人口基础数据库，要求"每位市民的身份证号、户籍地址、联系方式三项必须齐全，缺项即退回补录"。这主要体现了信息的（ ）。

**二、判断改错（3 小题，每题 2 分）**

今日无案例题，专注选择题。下面 3 句先判对错，错的写出错在哪里并改正：

1. 信息系统的组成要素中，硬件和软件是核心，人员可以不计入系统组成。
2. 信息化就是多买服务器、多上系统，设备越先进，信息化水平就越高。
3. 两化融合是指信息化与工业化融合，其目标是走新型工业化道路。

## ⑤ 参考答案与解析

**一、单选题**

1.B　2.B　3.C　4.B　5.C　6.A　7.B　8.C

**1. B**　解析："三项必须齐全、缺项退回"指向内容是否完备，即完整性。A 看是否赶在决策前，C 看成本收益之比，D 看能否独立核对，均不涉字段缺失。

**2. B**　解析：可验证性即可被独立核对、有据可查。A 把及时性说成精度，那是精确性；C 经济性讲投入产出比；D 安全性对电子数据同样是重点。

**3. C**　解析：《管理办法》是制度化的运行规则，属规程。A 是系统中记录的信息资源，B 是程序与文档，D 是传输设施。凡"管理办法、操作规范、审批流程"一律归规程。

**4. B**　解析：六要素中信息技术应用是龙头。A 信息资源是核心任务，C 人才是成功之本，D 信息网络是基础设施。

**5. C**　解析：信息技术和产业是物质基础。A 错，信息资源是核心任务；B 错，信息网络是基础设施；D 错，人才是成功之本，发展保障是政策法规和标准规范。

**6. A**　解析：五层次为产品、企业、产业、国民经济、社会生活信息化。B、C、D 都在前三个层次上做了错位替换，属典型顺序干扰项。

**7. B**　解析：设备联网采集参数是技术融合，用数据优化工艺是业务融合，把数据打包成服务外销是产业融合。A、C 各只取一段，D 明显错误。

**8. C**　解析："次日 6:00 前"是决策时点要求，对应及时性；"误差不超过 0.5%"是精度要求，对应精确性。可靠性看来源可信，完整性看字段齐全，题干均未提及。

**二、判断改错**

1. **错误**。信息系统由硬件、软件、数据、通信网络、人员、规程六要素组成。人员是使用者、维护者和管理者，不能省略；规程也不能缺，缺了数据质量就没有保障。
2. **错误**。信息化强调信息资源开发利用和信息技术推广应用，成效取决于应用深度与信息资源价值，而非设备数量。只堆设备、不建规程、不用数据，恰恰是典型的信息化失败。
3. **正确**。两化融合即信息化与工业化融合，以信息化带动工业化、以工业化促进信息化，目标是走新型工业化道路。
