## ② 核心知识精讲
### 2.1 资源管理全景：六个过程，两类资源
项目资源管理一共六个过程，按"规划—估算—获取—建设—管理—控制"排下来：

1. **规划资源管理**：定义如何估算、获取、管理和利用团队资源以及实物资源。
2. **估算活动资源**：估算执行项目所需的团队资源，以及材料、设备和用品的类型和数量。
3. **获取资源**：获取项目所需的团队成员、设施、设备、材料、用品以及其他资源。
4. **建设团队**：提高团队工作能力，促进团队成员互动，改善团队整体氛围，以提高项目绩效。
5. **管理团队**：跟踪团队成员工作表现，提供反馈，解决问题并管理团队变更，以优化项目绩效。
6. **控制资源**：确保按计划为项目分配和监督实物资源的使用，并根据需要采取纠正措施。

这里先把资源的两个类别分开，这是本章第一道坎：

- **团队资源**：就是人，包括项目经理、项目团队成员、专家、分包商人员。
- **实物资源**：设备、材料、设施、用品、场地等。

然后记住那条几乎年年考的分界线：**控制资源只管实物资源，团队资源由管理团队负责**。原因很朴素——人不能被"控制"式地分配调度，人的问题靠跟踪表现、反馈、解决冲突来处理，这是管理团队的活儿；而设备、材料是可以排期、调拨、监督使用的，才归控制资源。

一句话记：**人靠管，物靠控**。

### 2.2 规划资源管理：两份输出，各管一头
规划资源管理的作用，是根据项目类型和复杂程度，确定适用于本项目的资源管理方法和管理程度。小项目一份清单就够，大项目要写清每一类资源的获取路径和管控颗粒度。

工具四类：**专家判断**、**数据表现**（层级图、责任分配矩阵）、**组织理论**、**会议**。

输出两份，一定要分清楚：

- **资源管理计划**：项目经理视角的"资源打法说明书"。内容包括资源识别（需要什么资源）、获取资源（怎么拿到）、角色与职责（谁干什么、有什么权限）、项目组织图、项目团队资源管理（怎么建设和管理团队）、培训安排、团队建设活动、资源控制方式、认可与奖励计划。
- **团队章程**：团队自己约好的"行为公约"。内容包括团队价值观、团队共识、沟通指南、决策标准与决策过程、冲突处理过程、会议协议。

两句话对比：**资源管理计划是"我怎么管你们"，团队章程是"我们怎么一起干"**。团队章程由**团队共同制定**，这一点在选择题里最爱考——如果选项说"由项目经理单方面制定并下发"，直接排掉。

### 2.3 RACI：一张表把责任钉到人
责任分配矩阵（RAM）是把工作包或活动与团队成员对应起来的表格，RACI 是它最常用的一种写法。四个字母：

| 字母 | 含义 | 要点 |
|---|---|---|
| R | 执行（Responsible） | 真正动手干的人，可以有多个 |
| A | 负责（Accountable） | 最终对结果负责的人，**每项活动只能有一个** |
| C | 咨询（Consulted） | 决策前需要征求意见的人 |
| I | 知情（Informed） | 需要被通知结果的人 |

铁律只有一条：**一项活动只能有一个 A**。这不是形式主义——两个 A 就等于没人负责，出了事互相推，这是案例题里"职责不清、互相扯皮"的制度根源。R 可以多人，C 和 I 可以多人也可以没有。

考场上两个经典坑：把 A 理解成"亲自干活的人"（错，A 可能一天代码都不写，但他得为结果负责）；把 R 和 A 都设成多人（错，A 唯一）。

RACI 的实战价值在于把"我以为你会做"变成"表上写着你会做"。案例里出现"任务无人跟进""两个小组都以为对方在测接口"，答题时点出"未建立责任分配矩阵、职责与权限不清"就能拿到采分点。

### 2.4 组织架构：项目经理的权力从哪来
项目组织架构决定项目经理能调动多少资源、说话有多硬。三种基本形态：

先看两头：

| 对比项 | 职能型 | 项目型 |
|---|---|---|
| 项目经理权限 | 很小或无 | 很大，接近完全控制 |
| 资源可用性 | 有限，需向职能经理借 | 高，资源专属项目 |
| 预算控制者 | 职能经理 | 项目经理 |
| 项目经理角色 | 兼职，多为协调员 | 专职、全职 |

矩阵型再细分三档，判断标准就看三样：项目经理是不是专职、有没有专职的项目管理行政人员、预算谁说了算。

| 矩阵形态 | 项目经理角色 | 权限与资源控制 |
|---|---|---|
| 弱矩阵 | 协调员或联络员 | 权限有限，资源牢牢掌握在职能经理手中 |
| 平衡矩阵 | 有一定权威的项目经理 | 能与职能经理分权，但资源仍主要由职能经理掌控 |
| 强矩阵 | 专职项目经理 | 权限较大，组织中常设专职的项目管理行政人员 |

- **弱矩阵**：项目经理更像协调员或联络员，权限有限，资源牢牢握在职能经理手里。
- **平衡矩阵**：项目经理有一定权限，能参与资源调配，但职能经理仍是资源的主人。
- **强矩阵**：项目经理专职，拥有较大权限，组织中常设有专职的项目管理行政人员（PMO 常见于此），预算由项目经理与职能经理共同影响。

项目型组织里项目经理权力最大，代价是资源容易闲置、项目结束后人员安置麻烦；职能型组织里专业能力沉淀得好，代价是跨部门协作难、项目经理"有责无权"。

**组织理论**这个工具就是用来理解这些差异的：它研究组织行为方式，帮你判断在什么样的组织结构下该用什么样的沟通与协调方式。考场上它一般只作为"规划资源管理的工具之一"出现在选项里。

> **记忆抓手**：资源六过程"规、估、获、建、管、控"；人靠管、物靠控；RACI 里 A 只能有一个；权力从小到大——职能型＜弱矩阵＜平衡矩阵＜强矩阵＜项目型。

## ③ 高频易错点
1. **易错点**：认为控制资源过程也管团队资源 → **正解**：控制资源只针对实物资源（材料、设备、设施、用品）的分配与使用监督；团队成员的跟踪、反馈与变更属**管理团队**。
2. **易错点**：认为一项活动可以设多个 A → **正解**：责任分配矩阵中每项活动**只有一个 A**（最终负责人），R 可以多人；多个 A 实为无人负责。
3. **易错点**：把团队章程当成项目经理单方制定的制度文件 → **正解**：团队章程由**团队共同制定**，内容是价值观、共识、沟通指南、决策标准与冲突处理过程等行为约定。
4. **易错点**：把资源管理计划与团队章程混为一谈 → **正解**：资源管理计划是项目经理编制的资源管理方案（含角色职责、获取、培训、认可计划）；团队章程是团队的行为公约，二者作用不同。
5. **易错点**：认为矩阵型组织里项目经理权限一定大于职能经理 → **正解**：只有**强矩阵**才如此；弱矩阵中项目经理更接近协调员，权限有限，资源由职能经理掌控。

## ⑤ 参考答案与解析
**答案速查**：1.C　2.D　3.A　4.B　5.C　6.A　7.B　8.D

**1. C**　解析：获取资源就是把所需资源拿到手并分配到活动中。A 错在控制资源只管实物资源，团队表现由管理团队跟踪；B 错在建设团队属执行过程组；D 错在规划资源管理同时覆盖团队资源与实物资源。

**2. D**　解析：对最终结果负责是 A（张三），决策前提供意见是 C（王五）。A、B、C 均把 R 与 A 或 C 与 I 的位置弄错，其中 B 虽含 R、C，但把张三错认成执行者。

**3. A**　解析：RACI 的硬规则是每项活动只有一个 A、R 可多人。B 违背后者是为了担责；C 把 C（咨询）说成了 I（知情）；D 混淆了责任分配矩阵与层级图（如 OBS）的用途。

**4. B**　解析：团队章程由团队共同制定，写的是价值观、共识、沟通指南、决策标准与冲突处理过程。A 与"共同制定"相反；C 混淆了两份不同文件；D 时点错，团队章程在规划阶段形成并随团队发展更新。

**5. C**　解析：项目经理专职、权限较大、设有专职项目管理行政人员，是强矩阵的典型特征；但成员人事管理仍归职能经理，说明不是项目型。A、B 权限明显不足；D 不是教材中的基本组织形态。

**6. A**　解析：项目经理权限随组织从职能型向项目型演进逐步增大，矩阵型内部由弱到强递增。B 把弱矩阵排在职能型之前；C 把平衡矩阵与弱矩阵的顺序颠倒；D 是倒序。

**7. B**　解析：规划资源管理的输出是资源管理计划与团队章程。A 是估算活动资源的输出；C、D 中的物质资源分配单、项目团队派工单、资源日历属获取资源的输出。

**8. D**　解析：资源管理计划讲"怎么管资源"，团队章程讲"团队怎么一起干"。A 编制主体说反；B 错在资源管理计划是项目管理计划的组成部分；C 错在团队章程是团队共识文件，不需 CCB 批准。

**判断改错题参考答案**

（1）**错误**。控制资源只监督**实物资源**的分配与使用；跟踪团队成员表现、提供反馈、解决问题属**管理团队**过程。

（2）**错误**。责任分配矩阵中每项活动只能有**一个 A（最终负责人）**；A 可以有备份安排，但不能并列设置两个 A，否则等于无人负责。

（3）**正确**。团队章程由团队共同制定，内容包括团队价值观、共识、沟通指南、决策标准与过程、冲突处理过程、会议协议等。

（4）**错误**。弱矩阵中项目经理更接近**协调员或联络员**，权限有限，资源与预算主要由**职能经理**掌控；权限大于职能经理的是强矩阵或项目型。

（5）**正确**。资源管理计划包含资源识别、获取资源、角色与职责、项目组织图、团队资源管理、培训、团队建设、资源控制、认可计划等内容。
