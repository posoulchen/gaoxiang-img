## ② 核心知识精讲
### 2.1 三个基准值与四个绩效指标：C 管成本、S 管进度
挣值分析的全部计算，都建立在三个值上：

- **PV**（计划价值）：到某个时间点，**按计划应该完成**的工作值多少钱；
- **EV**（挣值）：到某个时间点，**实际已经完成**的工作值多少钱；
- **AC**（实际成本）：到某个时间点，**实际已经花掉**多少钱。

四个指标由此派生，记法只有一句：**C 开头看成本，S 开头看进度；减法得偏差，除法得指数**。

| 指标 | 公式 | 判读 |
|---|---|---|
| 成本偏差 CV | EV - AC | 大于 0 节约，小于 0 超支 |
| 进度偏差 SV | EV - PV | 大于 0 提前，小于 0 滞后 |
| 成本绩效指数 CPI | EV / AC | 大于 1 节约，小于 1 超支 |
| 进度绩效指数 SPI | EV / PV | 大于 1 提前，小于 1 滞后 |

注意两个细节：CV、SV 的单位是**货币**，CPI、SPI 是**无量纲指数**；EV 是同一个数，分别和 AC、PV 比，所以**成本看 AC，进度看 PV**，千万别把分母写反。这是选择题最高频的偷换点。

> **微型算例**：PV=500，EV=450，AC=480（万元）。CV=450-480=-30 万元（超支），SV=450-500=-50 万元（滞后），CPI=450/480≈0.94，SPI=450/500=0.9。

### 2.2 预测：EAC、ETC、VAC、TCPI 四个值一套流程
算完偏差，下一步是预测"照这样干下去，最后要花多少钱"。这里的分岔口是：**当前的偏差会不会持续**。

| 情形 | 判断依据 | EAC 公式 |
|---|---|---|
| 典型偏差（偏差将持续） | 题目说"按当前趋势继续""偏差不会改善" | EAC = BAC / CPI |
| 非典型偏差（偏差可纠正） | 题目说"剩余工作按原预算完成""已采取措施纠正" | EAC = AC + BAC - EV |

两个公式对应两种管理判断：典型偏差认为剩下的活还会按现在的效率干，所以用 CPI 一路折算到底；非典型偏差认为前面超支是偶发事件，剩下的活回到原预算，所以只把已花的 AC 加上剩余工作的预算（BAC-EV）。

其余三个值：

- **ETC**（完工尚需估算）= EAC - AC，即"从现在到完工还要花多少"；
- **VAC**（完工偏差）= BAC - EAC，大于 0 表示预计节约，小于 0 表示预计超支；
- **TCPI**（完工尚需绩效指数）= (BAC - EV) / (BAC - AC)，表示"剩下的钱要干出多少效率才能按原预算完工"；TCPI 大于 1，说明剩余工作必须比计划更省才追得回来。

> **微型算例**：BAC=1000，AC=300，EV=250，CPI=0.8。典型：EAC=1000/0.8=1250，ETC=950，VAC=-250；非典型：EAC=300+(1000-250)=1050，ETC=750。

### 2.3 成本超支：先找原因，再谈措施
案例题问"成本超支的原因"，不要只写"花钱多了"，要往管理过程上挂。高频原因有五类：

- **范围失控**：需求蔓延、变更未走流程、未经确认就增加功能，工作量凭空变大；
- **估算不准**：类比估算拍脑袋、未考虑风险、遗漏必要的管理和测试工作；
- **执行偏差**：返工多、质量问题导致重复劳动、资源效率低、加班费上涨；
- **进度拖累**：工期延长导致人工、场地、管理费等间接成本持续发生；
- **采购与风险**：合同计价方式不利、供应商涨价、风险发生后的应急支出超预期。

对策要与原因**一一对应**，而且要写过程动作：

- 范围失控 → 建立并执行整体变更控制，变更请求经 CCB 审批，更新成本基准；
- 估算不准 → 采用自下而上估算，参考历史数据和参数模型，重新编制预算；
- 返工多 → 加强质量保证和质量控制，开展质量审计，降低返工率；
- 进度拖累 → 分析关键路径，必要时赶工或快速跟进，但必须先评估赶工成本；
- 采购与风险 → 完善合同条款与验收标准，开展储备分析，动用应急储备需履行审批。

还要记一个概念边界：**应急储备**用于已识别风险，包含在成本基准内，由项目经理按规定动用；**管理储备**用于未识别风险，不包含在成本基准内，动用需要高层审批，动用后成本基准随之调整。这两个概念在综合知识和案例里都常考，别混。

### 2.4 成本案例的标准答法：五步写完
成本案例的答案比进度案例更"程式化"，按五步写，阅卷老师一眼就能找到采分点：

1. **抄数据**：把 PV、EV、AC、BAC 从题干里拎出来，列在答题区，防止代错数；
2. **算指标**：CV、SV、CPI、SPI 四个全算，写公式、代数、结果、单位，一步不省；
3. **判状态**：用文字说"成本超支、进度滞后"，不要只丢四个数字；
4. **做预测**：先判断典型还是非典型，再算 EAC、ETC，必要时补 VAC、TCPI；
5. **给原因与措施**：原因分条，措施与原因对应，最后写"更新成本基准、通知干系人"。

三个硬要求：**保留两位小数**（CPI、SPI 通常保留两位）；**单位统一**（万元不要和元混用）；**结论要有一句人话**（"按当前趋势，项目完工将超支 133.33 万元"）。

> **记忆抓手**：**"PV 计划、EV 挣到、AC 实花；CV 对 AC、SV 对 PV；典型除 CPI、非典型加剩余；ETC 减 AC、VAC 拿 BAC 减 EAC。"**

## ③ 高频易错点
1. **易错点**：把 CPI 和 SPI 的分子分母写反 → **正解**：CPI=EV/AC（成本），SPI=EV/PV（进度）；EV 永远在分子，分母看你要比的是"实花"还是"计划"。
2. **易错点**：不判断偏差性质，直接套 EAC=BAC/CPI → **正解**：先看题干有没有"偏差将持续""按当前趋势"的字样；若说"剩余工作按原预算"，必须用 EAC=AC+BAC-EV。
3. **易错点**：把 ETC 当成 EAC，或把 VAC 算成 EAC-BAC → **正解**：ETC=EAC-AC（还要花多少）；VAC=BAC-EAC（正数节约、负数超支）。
4. **易错点**：CV、SV 的符号判读反了 → **正解**：CV=EV-AC，负数超支；SV=EV-PV，负数滞后；指数小于 1 都是不利。
5. **易错点**：把应急储备和管理储备混用 → **正解**：应急储备应对**已识别风险**，在成本基准内，项目经理可按规定动用；管理储备应对**未识别风险**，在成本基准外，动用需高层审批。

A. 要求开发人员加班，把进度抢回来

**二、案例小问（1 题）**

【背景】某市建设城市运行管理平台，项目总预算 BAC=1200 万元，计划工期 12 个月。项目进行到第 6 个月末，项目经理统计得到：PV=600 万元，EV=540 万元，AC=600 万元。经分析，前 6 个月的成本偏差主要来自需求变更频繁和部分模块返工，项目组尚未采取有效的纠正措施。公司要求项目经理对完工成本和后续管理作出预测。

【问题1】计算第 6 个月末的 CV、SV、CPI、SPI，并判断项目的成本与进度状态。（8 分）
【问题2】若当前偏差按趋势持续，计算 EAC、ETC、VAC，并说明其含义。（6 分）
【问题3】若剩余工作按原预算完成，计算 EAC 和 ETC，并与问题2的结果比较。（4 分）
【问题4】分析该项目成本超支的主要原因，并提出针对性措施。（7 分）

## ⑤ 参考答案与解析
**答案速查**：1.A　2.A　3.C　4.B　5.B　6.B　7.C　8.B

**1. A**　解析：CV=EV-AC=450-480=-30 万元，成本超支；SV=EV-PV=450-500=-50 万元，进度滞后。B 符号全反；C 把两个公式的减数对调；D 符号错误。

**2. A**　解析：CPI=EV/AC=450/480≈0.94；SPI=EV/PV=450/500=0.90。B 是取倒数；C 把两个指数对调；D 两个都取倒数。

**3. C**　解析：偏差持续属典型偏差，EAC=BAC/CPI=1000/0.8=1250 万元。A 是用 BAC×CPI；B 是假设不超支；D 无依据。

**4. B**　解析：剩余工作按原预算属非典型偏差，EAC=AC+(BAC-EV)=300+(1000-250)=1050 万元。A 只加了 ETC 未加 AC；C 是按典型偏差计算；D 多加了 250 万元。

**5. B**　解析：ETC=EAC-AC=1250-300=950 万元。A 是 BAC-EV 的数值，属于非典型情形；C 是 EAC 本身；D 是 EAC+AC，公式错误。

**6. B**　解析：VAC=BAC-EAC=1000-1250=-250 万元，预计完工超支 250 万元。A 符号反了；C 是 ETC 的数值；D 公式错误。

**7. C**　解析：TCPI=(BAC-EV)/(BAC-AC)=(1000-250)/(1000-300)=750/700≈1.07。A 是取倒数；B 是 1.00，未考虑偏差；D 分母算错。

**8. B**　解析：超支根因是需求未经变更控制直接实施，属于范围蔓延，应对症下药建立整体变更控制、经 CCB 审批并更新成本基准。A 赶工只会进一步增加成本；C 压缩质量会带来更多返工；D 管理储备用于未识别风险，不能替代变更控制。

**案例参考答案要点**

**问题1（8 分）**

- CV = EV - AC = 540 - 600 = **-60 万元**，成本超支。（2 分）
- SV = EV - PV = 540 - 600 = **-60 万元**，进度滞后。（2 分）
- CPI = EV / AC = 540 / 600 = **0.90**，成本绩效不佳。（2 分）
- SPI = EV / PV = 540 / 600 = **0.90**，进度绩效不佳。（2 分）
- 结论：项目**成本超支、进度滞后**，每花 1 元只挣到 0.9 元价值，实际进度只达到计划的 90%。

**问题2（6 分）**

- 偏差持续属**典型偏差**，EAC = BAC / CPI = 1200 / 0.9 = **1333.33 万元**。（2 分）
- ETC = EAC - AC = 1333.33 - 600 = **733.33 万元**。（2 分）
- VAC = BAC - EAC = 1200 - 1333.33 = **-133.33 万元**，预计完工时超支约 133.33 万元。（2 分）

**问题3（4 分）**

- 剩余工作按原预算属**非典型偏差**，EAC = AC + (BAC - EV) = 600 + (1200 - 540) = **1260 万元**。（2 分）
- ETC = BAC - EV = 1200 - 540 = **660 万元**，或 ETC = EAC - AC = 1260 - 600 = 660 万元。（1 分）
- 比较：非典型情形下 EAC 比典型情形少 **73.33 万元**，说明"能否纠正偏差"直接决定预测结果；项目管理上应努力让剩余工作回到预算轨道，而不是默认偏差持续。（1 分）

**问题4（7 分）**

原因（4 分，每点 1 分，答出 4 点即可）：

- **需求变更频繁且未受控**：客户新增需求未经变更申请、影响分析和 CCB 审批，范围蔓延导致工作量增加。
- **返工造成重复投入**：部分模块质量不达标，测试后返工，人工成本和时间成本双重增加。
- **成本估算与预算编制不准确**：未充分考虑变更、返工和风险，预留的应急储备不足。
- **进度与成本联动失控**：进度滞后导致人工、管理等间接费用持续发生，进一步推高成本。
- **成本监控不到位**：未定期开展挣值分析，偏差发现晚，错过了纠偏窗口。

措施（3 分，每点 1 分，答出 3 点即可）：

- 建立并执行**整体变更控制流程**：变更申请→影响分析→CCB 审批→实施→更新范围、进度、成本基准。
- 加强**质量保证与质量控制**，开展质量审计，降低返工率，从源头减少重复投入。
- 定期开展**挣值分析与绩效审查**，发现偏差及时纠偏；对剩余工作重新估算，必要时申请动用**应急储备**，动用管理储备须履行高层审批。
- 与客户重新确认**范围基准和验收标准**，冻结非必要需求，必要时通过合同变更明确费用分担。
- 对关键路径上的滞后工作评估**赶工或快速跟进**的可行性，先算赶工成本再决策。
